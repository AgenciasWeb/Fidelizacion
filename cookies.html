No usamos cookies de publicidad ni de seguimiento

Esta web no usa cookies para publicidad, para medirte ni para seguirte por otros sitios. Tampoco usamos Google Analytics ni herramientas parecidas.

Qué guardamos en tu propio dispositivo

Para que la tarjeta funcione, la web guarda datos en el almacenamiento local de tu navegador (no son cookies y no se envían a otros). En concreto:

  • El código de tu tarjeta (por ejemplo, el código de sellos) para mostrártela cuando volvés a entrar.
  • El código del negocio y, en el panel del negocio, el PIN, para que el panel recuerde con qué negocio estás trabajando.
  • Un aviso de que ya leíste este mensaje, para no mostrártelo cada vez.

Esta información se queda en tu celular o computadora. Podés borrarla cuando quieras desde la configuración de tu navegador (borrar datos de sitios) o usando el botón "Borrar mi tarjeta y mis datos" dentro de la tarjeta.

Servicios externos

La web se apoya en Supabase (base de datos) y GitHub Pages (alojamiento), que pueden registrar datos técnicos básicos para funcionar y proteger el servicio (por ejemplo, la dirección IP y la fecha del pedido). Cuando tocás un enlace de WhatsApp, se abre WhatsApp y allí se aplican las políticas de WhatsApp (Meta).

Cómo controlar el almacenamiento

Desde tu navegador podés bloquear o borrar el almacenamiento local. Si lo borrás, vas a tener que volver a crear o recuperar tu tarjeta.
